##  CodeNite-Unity-Game

An **E-Learning Coding App for Kids** built as a Unity project.  
This repository contains the full Unity game source code and assets intended to teach or give kids an interactive coding-themed game experience.  
It’s developed with **Unity Engine**, using C# for gameplay logic and editor integration.

## 🧠 Project Overview

**CodeNite** is designed as an educational game that helps kids interact with programming concepts and enjoy learning in a playful environment. The game is built using the Unity game engine, a powerful platform widely used for both 2D and 3D games and simulations in C#:contentReference[oaicite:2]{index=2}.

## ⚙️ Key Features

- 🎯 **Unity-based gameplay** — developed using the Unity Engine
- 🎓 **Educational focus** — teaches coding concepts via gameplay
- 🧩 **Interactive environment** — engaging rules and mechanics
- 🎨 **Assets & Scenes included** — game visuals and interactive components
- 📦 Full Unity project structure (Assets, Packages, ProjectSettings)

> 🚀 Suitable for learners, educators, and developers interested in Unity game creation and game-driven learning mechanics.
